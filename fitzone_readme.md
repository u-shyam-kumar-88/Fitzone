# 🏋️ Fitzone — Modern Fitness & Gym Web Application

A modern, responsive fitness and gym web application crafted with **semantic HTML5**, **modern CSS3**, and **vanilla JavaScript**. Designed with a high-energy athletic aesthetic, interactive workout and membership sections, and dedicated user authentication.

🔗 **GitHub Repository:** [https://github.com/u-shyam-kumar-88/Fitzone](https://github.com/u-shyam-kumar-88/Fitzone)  
🌐 **Live Demo (GitHub Pages):** [https://u-shyam-kumar-88.github.io/Fitzone/](https://u-shyam-kumar-88.github.io/Fitzone/)

## ✨ Features & Sections

### 1. 🧭 Navigation Bar & Authentication
- **Responsive Header**:
  - Brand identity with quick links to **Home**, **Programs**, **Trainers**, **Pricing**, and **Contact**.
  - Dedicated **Login / Sign Up** access linking seamlessly to `login.html`.
  - Mobile-friendly menu toggle for effortless navigation across all screen sizes.

### 2. 🌟 Hero Showcase
- High-impact fitness banner with bold motivational typography and call-to-action buttons (*Join Now*, *Explore Programs*).
- Dynamic visual layout designed to highlight gym facilities, coaching, and transformation goals.

### 3. 💪 Training Programs & Workouts
- Structured program cards covering **Strength Training**, **HIIT & Cardio**, **Yoga & Flexibility**, and **Personal Coaching**.
- Clean hover transitions, clear descriptions, and responsive multi-column grids.

### 4. 🧑‍🏫 Expert Trainers & Membership Plans
- **Certified Trainers**: Profile cards showcasing coaching specialties and social links.
- **Flexible Pricing Tiers**: Clear comparison of Monthly, Quarterly, and Annual gym memberships with highlighted best-value plans.

### 5. 🔐 Dedicated Login & Registration (`login.html`)
- Clean, user-friendly authentication page with form validation and interactive UI transitions powered by `script.js`.

### 6. ⚡ Interactive Functionality (`script.js`)
- Smooth scrolling, interactive navigation toggles, dynamic UI feedback, and client-side form handling.

---

## 🎨 Design & Aesthetic Highlights

- **High-Energy Dark & Athletic Palette**: Bold contrast pairing deep dark backgrounds with vibrant accent highlights.
- **Responsive Layouts**: Built using CSS Flexbox and CSS Grid (`style.css`) for fluid adaptation across desktop, tablet, and mobile devices.
- **Clean Architecture**: Modular separation of structure (`index.html`, `login.html`), styling (`style.css`), and interactivity (`script.js`).

---

## 📱 Fully Responsive Breakpoints

| Device | Breakpoint | Adaptations |
| :--- | :--- | :--- |
| **Desktop / Ultrawide** | `> 1200px` | Full multi-column grids, expanded navigation bar, and full-width hero showcase. |
| **Laptop** | `992px – 1200px` | Balanced 3-column program and pricing layouts with scaled typography. |
| **Tablet** | `768px – 991px` | 2-column card grids and adaptive hero spacing. |
| **Mobile** | `< 768px` | Collapsible mobile menu, stacked single-column cards, and touch-friendly buttons. |

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Option 1: Directly open the file in your default browser
start index.html    # Windows
open index.html     # macOS
xdg-open index.html # Linux

# Option 2: Run a local static server
npx serve .
# or
python -m http.server 3000
```
